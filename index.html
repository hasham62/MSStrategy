Backup & settings

Move your records between Windows and iPhone manually.

Keep your journal safe

Your entries are stored locally in this browser, not on a shared server. The iPhone and Windows copies will not automatically sync. If you redeploy to your existing website URL, records already stored in that browser should remain available. Export a backup before updating. Export on one device and import on the other to transfer records.

Imports merge by record ID. If you have edited the same trade independently on two devices, the imported copy will replace that trade on this device.

Install on your devices

iPhone

Open your Netlify website in Safari → Share → Add to Home Screen → Add.

Windows

Open the same website in Microsoft Edge or Chrome, then use the browser's Install app / Install this site as an app option. You can also use it as a normal website.

For the same website address as your existing app, deploy this updated ZIP to your existing Netlify site. Do not create a new site if you want to keep the address.

MS Strategy App is a personal journaling and discipline tool, not trading advice. Checklists are not guarantees of performance. Back up your journal regularly.
